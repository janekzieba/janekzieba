# Hi there! 👋 I'm Jan Zięba

## About Me

I am a **System Analyst** and **Software Engineering** enthusiast currently pursuing a **Master’s Degree in Computer Science in Engineering** at **AGH University of Science and Technology** in Kraków.

I hold a **B.Sc. in Computational Engineering**, where my engineering thesis focused on building a machine learning system for inflation prediction in Poland using time-series analysis. For my Master's thesis, I am researching: **"Experimental Evaluation of the Robustness of Financial Time Series Forecasting Models to Distribution Shifts"**.

In my daily professional role, I specialize in enterprise integration testing, API analysis, automated testing, defect triaging across complex distributed architectures, business logic design, and translating business needs into comprehensive technical specifications.

Alongside systems and data engineering, I work as a **Graphic & Web Designer**, merging robust software backend logic with clean, minimalist UI/UX design and modern frontend development.

* 🔭 **Current Focus:** Financial time-series robustness, machine learning model resilience against distribution shifts, and scalable enterprise architecture.
* 🌱 **Currently learning:** Solution & Cloud Architecture, advanced AWS services, and distributed microservices design.
* 💬 **Ask me about:** **System Analysis**, **API Integrations**, **Python**, **Machine Learning**, **Time-Series Analysis**, **Software Engineering**.
